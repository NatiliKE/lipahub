# LIPAHUB SEO website

## Files
- `index.html` — responsive landing page and introductory blog content
- `robots.txt` — allows search crawlers and points to the sitemap
- `sitemap.xml` — homepage sitemap

## Publish
Upload all three files to the public web root for `https://lipahub.com/` (usually `public_html/` or the hosting provider's document root). The homepage must be available at `https://lipahub.com/`.

If you are using GitHub Pages, upload `index.html` to the repository's published root (or the configured Pages folder). GitHub Pages is static hosting; it will not run PHP. This page links to the existing PHP registration URL but does not replace the registration backend.

## After publishing
1. Open `https://lipahub.com/` and test the registration button on mobile.
2. Open `https://lipahub.com/robots.txt` and `https://lipahub.com/sitemap.xml`.
3. Add `https://lipahub.com/` as a property in Google Search Console and submit `/sitemap.xml`.
4. Share the public page on social accounts and encourage genuine links/mentions.
5. Publish original, useful blog articles regularly. Do not keyword-stuff or promise guaranteed earnings.

Google does not guarantee indexing or a first-page ranking. Search visibility depends on crawlability, useful original content, reputation, competition and time.
